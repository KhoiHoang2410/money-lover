# Visual direction: Gradient Rings

> **Status: superseded by [ADR-0010](0010-visual-direction-calm-neobank.md).** The Gradient Rings language below was the original direction; the app is being re-skinned to a calm neobank look. Kept for history.

After reviewing three throwaway browser prototypes (Soft Cards, Bold Editorial, Gradient Rings), the owner chose **Gradient Rings** as the visual language: a pink→yellow gradient hero header, circular progress rings for Goals, a dense tile + list dashboard, and a floating dark dock for navigation. Palette pink/white/yellow, icon-first (SF Symbols), minimal text, tasteful motion.

This sets the look-and-feel all screens are built against; changing it later means re-skinning every screen, so it is recorded. The losing prototypes and the prototype harness under `prototype/` are throwaway and should be deleted once the direction is folded into the SwiftUI views.
